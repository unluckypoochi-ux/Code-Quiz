# CodeQuiz - Online Quiz Portal

A web development internship project built with HTML, CSS and JavaScript.

## Features
- Topic selection: HTML, CSS, JavaScript
- Random question order
- Instant correct/wrong feedback with explanation
- Final score with answer review
- Best score saved using localStorage
- Light/dark theme, responsive layout

## Technologies
HTML5, CSS3 (Flexbox, Grid, CSS variables), JavaScript (DOM, events, arrays, localStorage)

## Folder structure
```
CodeQuiz/
  index.html
  css/style.css
  js/script.js
  README.md
```

## How to run
Open `index.html` in a browser, or use the Live Server extension in VS Code.
